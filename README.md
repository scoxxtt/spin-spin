# SPIN! SPIN!

原創美式漫畫 × Cyberpunk 風格的陀螺對戰網頁遊戲。手機或電腦瀏覽器打開就能玩：

**▶ https://scoxxtt.github.io/spin-spin/**

## 遊戲特色
- **抽卡組隊**：角色卡、武器、鎧甲分開收藏在零件庫，拖曳到出戰格就能換裝，排好 1・2・3 出場順序
- **稀有度與升星**：白＜紫＜紅＜黃，同名零件合成升星（最多 3 星），還有付費抽限定的隱藏角色
- **武器三系相剋**：近戰、射擊、爆裂三系，對上輕裝、重裝、能量護盾各有剋制
- **熱血開場**：選落點、拉弓瞄準，「3、2、1、SPIN! SPIN!」雙方同時發射
- **爽快對戰**：按住拖曳移動、點畫面充能 EX，WORMHOLE 加速軌道、CORE 增傷圈，撞進 BLOOD +2、DEAD +3 出口得分
- **漫畫打擊感**：BOOM、SLASH 等漫畫字、集中線、引擎聲浪音效
- **掛機友善**：AUTO 自動發射、自動 EX、自動下一局

## 玩法
三場制，你的第 1、2、3 顆依序對上對手。爆甲 +1、BLOOD +2、DEAD +3，總分高者勝。打贏拿金幣再抽卡變強！
